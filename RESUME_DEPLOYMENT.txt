## 📋 PROCHAINES ÉTAPES (TRÈS SIMPLES!)

### ÉTAPE 1: Libérer l'espace disque (5 minutes)
1. Allez sur: https://www.pythonanywhere.com/user/chouchoum/files/
2. Supprimez les dossiers/fichiers anciens (sdi_site, sdi_site_new, mysite, etc.)
3. Cela libérera ~150MB

### ÉTAPE 2: Cloner le projet (2 minutes)
1. Ouvrez une console Bash: https://www.pythonanywhere.com/user/chouchoum/consoles/
2. Lancez les commandes:
```bash
cd ~
git clone https://github.com/cenadyonlineschool100-ui/sdi-marche-mondial-unit-50.git sdi-market
cd sdi-market
git checkout feature/ma-modif
```

### ÉTAPE 3: Configurer l'environnement (5 minutes)
```bash
mkvirtualenv --python=/usr/bin/python3.11 sdi-market
pip install -r requirements.txt
python manage.py migrate --noinput
python manage.py collectstatic --noinput
deactivate
```

### ÉTAPE 4: Configurer le WSGI (3 minutes)
1. Allez sur: https://www.pythonanywhere.com/user/chouchoum/webapps/
2. Cliquez sur: chouchoum.pythonanywhere.com
3. Cliquez sur le lien du fichier WSGI
4. Remplacez le contenu (voir GUIDE_COMPLET_PYTHONANYWHERE.md)
5. Cliquez "Save"

### ÉTAPE 5: Configurer les fichiers statiques (2 minutes)
1. Sur la même page, scroll jusqu'à "Static files"
2. Ajoutez:
   - `/static/` → `/home/chouchoum/sdi-market/staticfiles/`
   - `/media/` → `/home/chouchoum/sdi-market/media/`

### ÉTAPE 6: Recharger l'application (1 minute)
1. Cliquez sur le bouton "Reload" (🔄) en haut
2. Attendez que ça passe à "running"
3. Visitez: https://chouchoum.pythonanywhere.com/

**TOTAL: ~20 minutes ⏱️**
